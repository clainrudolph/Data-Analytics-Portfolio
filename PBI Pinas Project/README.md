## Dataset

The dataset focuses on Flood Control Projects (FCP) and other infrastructure initiatives managed by the Department of Public Works and Highways (DPWH). 

- **Data Source:** DIME Project (Digital Information for Monitoring and Evaluation)  
- **Data Preparation:** Curated by DAXJutsu and OppaBI for the challenge  
- **Host:** Power BI Pilipinas Community Facebook Group

*Note: This project was completed as a personal practice exercise to strengthen my Power BI skills.*
