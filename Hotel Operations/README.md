# Customer Satisfaction Analysis

**Description:** The learning project from the DataCamp practical exam for SQL Associate – Hotel Operations. The goal is to analyze customer feedback data to identify causes of dissatisfaction and highlight hotel branches and services that need improvement.

**Tools:** DataCamp DataLab (SQL) – projects were completed in the online IDE and downloaded as Jupyter Notebook (.ipynb) files for upload to GitHub.

**Skills:** SQL, data management, exploratory data analysis (EDA), data cleaning, handling missing values, grouping and aggregating data, filtering and subsetting, calculating averages and maximums, and rounding numerical values.

## Dataset

The dataset of a fictional hotel branch and customer feedback system is from [DataCamp](https://app.datacamp.com/certification/technology-certifications/sql-associate/overview). 

It consists of three tables: Branch, which holds branch details such as location, total rooms, staff count, opening date, and target guest segment; Service, which contains descriptions of services offered; and Request, which records customer service requests linked to both a branch and a service, along with metrics like time taken, request timestamp, and customer rating.
